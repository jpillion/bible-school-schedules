Privacy Policy

Bible School Schedules (CBSSA) · Last updated 17 October 2026

This app does not collect your name, email address, or any other personal detail. It has no analytics, no advertising, no crash reporting, and no tracking.

To get your school's schedule onto your phone, the app does talk to a server, run on Google Firebase. This page says exactly what that involves.

What is sent, and why

  • An anonymous app identifier. The first time the app connects, Firebase Authentication gives this copy of the app a random identifier. It is not tied to your name, email, phone number or any account — it exists only so the server can remember which schedules this copy of the app has been given access to.
  • The access code you type. When you enter your school's access code, it is sent to the server to be checked. If it is right, the server records that this anonymous identifier may read that school's schedule. Codes are not stored with the identifier.
  • Your school's schedule. The app then downloads the schedule and keeps a copy on your phone, so it works with no signal and updates when the school publishes a change.

What the server keeps

  • Which anonymous identifiers have access to which schools.
  • To slow down anyone guessing codes, a count of recent wrong attempts — per anonymous identifier, and per network address stored only as a scrambled (keyed hash) value, never the address itself. These counters delete themselves after seven days.
  • Like any internet service, Google's servers may record the network (IP) address of a request in their own logs. That is covered by Firebase's privacy and security terms.

What stays on your phone

  • The schedules you have added.
  • Your settings — whether reminders are switched on, and how many minutes' notice you want.

Deleting the app deletes all of this from your phone. The server then holds only an anonymous identifier that nothing links to you; if you would like it removed anyway, email the address below.

What the app does not do

  • It does not ask for your name, email address, or any other personal detail.
  • It does not use analytics, crash reporting, or any advertising or tracking service.
  • It does not request your location, contacts, photos, microphone, or camera.
  • It does not share or sell any data.

Notifications

If you switch reminders on, the app asks your phone's operating system for permission to show notifications. The reminders are then scheduled by the phone itself, from the schedule already stored on it. No reminder is sent from a server, and no push notification service is used — which is why reminders keep working when there is no signal at the camp.

Permissions, and why each one is needed

  • Notifications — to show the event reminders you asked for.
  • Exact alarms (Android) — so that "10 minutes before" actually means ten minutes before, rather than whenever the system next gets round to it.
  • Run at startup (Android) — scheduled alarms are discarded when a phone restarts; this permission lets the app quietly set them again.

The Home Screen web version

The web version at this site does not connect to the server described above. It stores the schedule in your browser's cache so it works offline, sets no cookies, and sends nothing anywhere. This site is hosted on GitHub Pages; as with any web host, GitHub may keep its own server logs of requests, which is outside our control and covered by GitHub's privacy statement.

Children

The app is a personal schedule and reminder tool. It is not directed at children, and it collects no personal information from anyone, children included.
